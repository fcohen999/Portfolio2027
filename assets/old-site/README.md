# Old site images (fionacohendesign.com)

Full-resolution images from the Framer version of the site, archived as
source material for the redesign. One folder per page:

| Folder | Page | Files |
|---|---|---|
| `home/` | Homepage: project covers, client logos, profile photo, site share image | 12 |
| `merck/` | Merck Vaccination Explorer | 7 |
| `erma/` | J.P. Morgan Risk Management Dashboards | 18 |
| `cdc/` | CDC OneLab REACH, including its design-system sheets (`image-03` to `image-10`) | 16 |
| `outage-modeler/` | J.P. Morgan Asset Outage Modeling Tool | 10 |
| `tth/` | DOJ Time to Hire | 12 |
| `yaffed/` | YAFFED.org | 7 |
| | **Total** | **82** |

Each folder holds the images in `files/`, plus `asset-manifest.md`. Open
that file to see each image's size and original URL, with a link to
the file. `asset-manifest.json` has the same information in a
machine-readable form.

The site-wide share image (the "Fiona Cohen" card) appeared on every
page; it is kept once, in `home/`. No two files in the archive are
identical.

Every file is the largest version the old site served. Nothing was
upscaled or re-encoded.

Fetched 2026-10-01 with fetch-web-assets (kept outside this repo).
