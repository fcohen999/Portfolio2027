# Image Checklist

Export these from Framer (or source fresh for the two new projects) and
drop them into a local folder using these filenames — I'll reference them
by name and won't substitute placeholder imagery without asking first.

This checklist is based on the recommended site structure. It's complete
for the pages I know about (homepage, resume, Sound Transit, Sport
Shepherd); the existing-case-study rows are placeholders until you confirm
what's actually live (see the gap flagged in `00-content-inventory-and-audit.md`).

## Homepage

- `headshot.jpg` — your photo, if the hero includes one (optional per the
  layout spec — the hero as written is text-only; include this only if you
  want a portrait in the hero or footer)
- One thumbnail per case study for the index row, e.g.:
  - `thumb-sound-transit.jpg`
  - `thumb-sport-shepherd.jpg`
  - `thumb-[existing-project-1].jpg` (repeat per confirmed existing project)
- Any client logos you want in the credibility strip (optional — the spec
  as written uses text stats, not logos): `logo-[client].svg` per client

## Every case study page (template — repeat per project)

- `[project]-hero.jpg` — the hero image at the top of the page
- `[project]-screenshot-01.jpg`, `-02.jpg`, `-03.jpg`, etc. — supporting
  screenshots for the narrative/screenshot-grid sections
- `[project]-diagram-01.jpg` — any IA diagrams, flowcharts, or system
  diagrams referenced in the copy
- `[project]-before.jpg` / `[project]-after.jpg` — for any project with a
  before/after narrative
